## shell

Use case: ui-mockup. Create a professional high fidelity DESIGN COLLAGE for BEVYLITE, a native Bevy ECS game editor. This is an annotated concept board, not a screenshot of implemented software. Landscape editorial board with generous outer margins and readable typography. Consistent neutral graphite design system: canvas #101318, panels #161b22, input fills #202630, primary text #e5e9f0, secondary #929baa, restrained cyan #45c5db ONLY for selected/active state. Segoe UI / Inter sans serif, numeric values monospaced. Small consistent 16px outline icons, no emoji. Modern flat desktop productivity UI. NO outline around every row, NO outlined nested cards, NO pill-button soup, NO neon glow, NO gradients. Use quiet tonal surfaces, whitespace and occasional thin horizontal/vertical separators only at major region boundaries. Show filled numeric fields with NO default border and only the keyboard-focused field with a fine cyan focus outline. All component UI must look calm, precise and practical. Realistic readable labels, not huge body text. Important: a subtle panel divider is fine; drawing a bounding box around every control is forbidden.
Board title: "01  WORKSPACE + GAME VIEW". Four composed views in a clean 2x2 collage, each clearly numbered.
A large view labeled "Edit workspace": complete editor shell, slim top menu BEVYLITE / Courtyard / File Edit View Entity Build, a quiet second toolbar with select/move/rotate/scale icons, Local dropdown, central Play Pause Stop controls. Left 250px hierarchy, large center viewport of a simple stone gate courtyard with material test spheres, right 340px inspector, bottom Assets Relations Console Jobs dock. Each region separated by a single divider. No box around every tree row.
Second view labeled "Focused Game View": separate game preview window with just game scene and small unobtrusive in-game instruction HUD "Space / E: gate   RMB: orbit   Esc: release   F8: Stop". Editor visible calmly behind. Game preview has input-focus indicator, no scene-edit gizmos or editor widgets.
Third view labeled "Panel interactions": a panel tab being dragged with a translucent drop preview and one highlighted split edge; visible discreet resize handle, layout presets and reset layout option. Show these as proposed interactions, not working claims.
Fourth view labeled "Quiet defaults": close-up toolbar neutral state, cyan active tool only, icon-only common actions with one tooltip, background job progress in status bar, keyboard focus on one control. Tiny annotation "Persistent: tools, selection, transport. Contextual: details, actions, diagnostics."
Design hierarchy is panels > section titles > content. Keep 70 percent of visible surfaces borderless.
